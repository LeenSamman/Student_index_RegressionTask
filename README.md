# Student_index_RegressionTask

## THE TARGET OF THIS ANALYSIS IS TO UNDERSTAND HOW VARIOUS FACTORS INFLUENCE THE PERFORMANCE INDEX OF A STUDENT.
- Linear regression, decision tree and random forest were used in this task . THE LEAST ERROR EVALUATED WAS BY LINEAR REGRESSION

- the code include concise correlation analysis and feature engineering depending on the highest correlations with the target . note that the code is well commented for the reader to understand.
